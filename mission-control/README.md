# Bailey OS — Mission Control

Static pages for GitHub Pages, served from `/BaileyOS-/mission-control/`.

| Page | What it is |
|---|---|
| `index.html` | Mission Control dashboard (was `dashboard.html`) |
| `ark-dashboard.html` | Bailey ARK verification log (live Supabase reads) |
| `living-archive.html` | Living Archive visualizer of ARK entries (was `signal-ark.html`; renamed so it is not a second Signal Ark) |
| `burst-preview.html` | Canon Burst preview |
| `intent-engineering.html` | Intent Engineering worksheet (stored in this browser only) |
| `alignment-compass.html` | Alignment Compass (stored in this browser only) |
| `manifest.json`, `sw.js`, `icon-*` | Install-to-home-screen support (network-first for pages) |

## Notes
- Supabase reads use the public anon/publishable key only; no service-role key is included.
- The Slack "Send signal" button asks for a webhook URL and keeps it in this browser's localStorage; none is shipped.
- Text from the database is HTML-escaped before display.
- The age gate confirms that a verification request was accepted by the `verify-age` edge function and logs a token/outcome row. It does not, by itself, prove a person's identity or age beyond what that function checks.
- Personal contact details, account/tenant names, and local dev-server details were removed; location shown is Grand Junction, CO.
